# 🏅 Olympics Data Analysis

An Exploratory Data Analysis (EDA) project that examines historical Olympic Games data to uncover trends, patterns, and insights into athlete participation, medal distribution, countries' performances, and demographic characteristics. The analysis is performed using Python and popular data science libraries within a Jupyter Notebook.

---

## 📌 Project Overview

This project analyzes historical Olympic data to answer questions such as:

- Which countries have won the most medals?
- How has athlete participation changed over time?
- What is the age distribution of Olympic athletes?
- Which sports have been the most popular?
- How does gender participation vary across different Olympic Games?
- Which athletes and nations have achieved the greatest success?

The project demonstrates the complete Exploratory Data Analysis (EDA) workflow, including data cleaning, preprocessing, visualization, and insight generation.

---

## 📊 Dataset

The project uses the **120 Years of Olympic History** dataset, containing information about:

- Athlete details
- Olympic Games
- Sports and events
- Medal records
- Participating countries
- National Olympic Committee (NOC) regions

Files included:

```
data/
├── athlete_events.csv
└── noc_regions.csv
```
